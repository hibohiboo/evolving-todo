# browser-check（ブラウザで確かめるときの呼び出し口）

**メインのセッションでは画像を読まない。** 下の1〜3は、Agent ツールでサブエージェント（`general-purpose`、`model: sonnet`）に任せる。依頼文には、確かめる画面と操作の流れ、見るべき点（プランの受け入れ条件）、スクリーンショットの保存先（スクラッチパッドの `shots/`）を書き、「画像を見て確かめた結果を文字で報告し、撮ったファイルのパスを並べる」と頼む。スクリーンショットは一度読むと、その後の全ターンでコンテキストに残って読み直される。

1. `pnpm web:dev:agent` を Bash の `run_in_background` で起動する（http://localhost:5174。人間の開発サーバー 5173 番と取り合わない）
2. ブラウザ（Playwright など）で、変更した画面を通しで操作して確かめる。読み直すと MSW のメモリ上の状態が消える
3. 終わったら、起動したバックグラウンドのタスクを止める（タスクが時間切れで止まったときも）
