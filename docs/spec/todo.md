# TODO

このアプリの仕様の正式ページ（SSOT）。コード（`packages/domain` の型・`apps/web` の画面）はここの用語と決まりに合わせる。決まっていないことは[未解決論点](../open-questions.md)に置き、ここには書かない。

## 用語

| 用語 | 意味 |
|---|---|
| TODO | やること1件。タイトルと、完了したかを持つ |
| 完了 | やり終えた TODO の状態。完了を戻すと、未完了に戻る |
| 残りの件数 | 未完了の TODO の件数 |

## 一覧

- 画面には TODO の一覧と、残りの件数を出す
- 完了した TODO は、一覧に残したまま、完了と分かる見た目にする
- TODO が1件も無ければ、無いと出す
- 読み込めなければ、読み込めなかったと出す

## データ

バックエンドは無い。`/api/*` は MSW が応答し、状態はメモリ上にだけあり、リロードで消える。
