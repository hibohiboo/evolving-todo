# ロードマップ

プロダクトのゴールと、そこへ向かうマイルストーンの**定義**だけを置く。進み具合（どの要望が済んだか）はここに書かず、[要望（バックログ）](backlog/index.md)の各ファイルに書いた「どのマイルストーンか」と状態から、[トップページのダッシュボード](/)が計算して見せる。

定義の正はこのページの先頭（frontmatter）。

## mvp

1人で TODO を管理できる。完成の条件：

1. TODO を追加できる
2. TODO を完了にでき、完了を戻せる
3. TODO を消せる
4. 残りの件数が分かる

## organize

やることを整理できる。完成の条件は、mvp の完成時に詰める。
